# NeuSim / Ramulator DSE

Request-level VLA exploration following the two-track workflow in `vlasim.zip`:
run fast DSE against a versioned DRAM uncertainty interval while collecting slow
calibration measurements independently. Use held-out segments to validate selected
designs before making hardware claims.

## Reproduce

From the repository root (Python 3.10+):

```bash
uv sync --extra test
uv run python -m pytest -q
uv run python vlasim/tests_check.py
uv run python vlasim/run_sweep.py vlasim/calib/dram_v0_prior.json --small --out results/v0/nominal
uv run python vlasim/robustness.py vlasim/calib/dram_v0_prior.json --small --points 3 --out results/v0/robust
uv run python vlasim/check_candidates.py results/v0/robust/shortlist.csv vlasim/calib/dram_v0_prior.json --out results/v0/candidates
```

Remove `--small` for the full space: 10,752 hardware/mapping configurations.
The small space contains 174 configurations across 12 hardware points (1-4 cores,
100/200/400 GB/s, 32 MB shared SRAM, 2048 KB private SRAM per core).
`--procs 1` disables multiprocessing; `--n-req` controls the simulation length.
The default latency budget is a provisional **mean L <= 250 ms**, not a task-derived
requirement or a p95 constraint. Change it with `--L_max_ms`.

The archive's `vlasim/data/*.csv` files are imported historical examples, not outputs
regenerated by this repository. New experiments go in ignored `results/` directories.

## Decision Outputs

- `robust_LS.csv`: all configurations at every sampled DRAM point.
- `robust_summary.csv`: per-configuration L/S extrema and S spread.
- `decision_report.json`: full calibration, budget, request count, sensitivity and
  per-hardware status, including infeasible hardware separately from stable winners.
- `shortlist.csv`: one mapping per hardware minimizing worst sampled S subject to
  satisfying the mean-L budget at every sampled point.

Mapping identity includes every mapping field. Stability is only over the finite
sample set, not a proof over the continuous interval, and does not mean a design is
ready for tape-out. Nominal points and exact nominal-axis endpoints are added to
the Cartesian grid for sensitivity analysis.

## Calibration Track

```bash
uv run python vlasim/ramulator_bridge/gen_traces.py micro --total-mb 64 --out results/calibration/micro
# Run the traces through a compatible backend frontend and collect measured CSV rows.
uv run python vlasim/ramulator_bridge/fit_dram.py measured.csv vlasim/calib/dram_v0_prior.json vlasim/calib/dram_v1.json --metadata backend.json
uv run python vlasim/robustness.py vlasim/calib/dram_v1.json --small --out results/v1/robust
uv run python vlasim/ramulator_bridge/gen_traces.py segment --calib vlasim/calib/dram_v1.json --out results/v1/segments
```

Trace generation writes a manifest with byte counts, write counts and SHA-256 hashes.
`--config candidate.json` accepts `hardware` and `mapping` dictionaries using the
dataclass field names for replaying a specific candidate. These CSV traces are an
interchange format, **not** directly executable Ramulator input. The backend adapter
must preserve issue timing, stream tags, backpressure and priorities where supported.
The generator does not run a backend. Segment replay currently distributes traffic
uniformly over each op and treats all traffic as reads: it is a coarse validation
input, not an exact burst/read-write trace.

Measured CSV columns: `benchmark,peak_GBps,achieved_GBps` and, for priority,
`hi_achieved_GBps,hi_demand_GBps`. Record backend revision, device organization,
address mapping, clock, queue limits, controller, saturation/issue policy and
measurement window in `backend.json`. Do not mix incompatible device setups in one
fit. Priority leak cannot be inferred from an unsaturated stream's demand alone:
use a controlled, achievable isolated reference or leave it uncalibrated.
Fits preserve unmeasured parameters and metadata. Bounds are empirical padded
ranges, not confidence intervals; contradictory measurements can expand a prior.

## Integration Gates

1. **Current:** portable analytical DSE plus an executed native Ramulator calibration
   track on `einst`, with isolated builds and recorded source/library/trace hashes.
2. **DRAM:** 24 native calibration cases and matched 60-configuration sweeps are
   complete. Balanced-reference v2 passes paced overlap replay, but independent
   mixed-capacity point predictions fail the 10% gate (about 42% error). Its broad
   empirical interval covers the tested cases; it is not a universal mixed model.
   Strict priority is unsupported and remains uncalibrated.
3. **Compute:** explicit VLM/DiT GEMM decomposition and real `NeuSimCompute.gemm_ns`
   execution are implemented and exercised on unsliced arrays (69 unique shapes,
   14 hybrid simulations). Strict mode rejects unresolved SigLIP; analytical
   fallback requires explicit opt-in. Vector/norm costs, checkpoint verification
   and row-slicing lowering remain unvalidated. These are not full compute results.
4. **Validation:** held-out paced windows and independent capacity probes are
   executed. All 6 shortlisted candidates at all 33 DRAM points pass deterministic
   30/120-request convergence. Independent captured VLA replay remains missing.
   The prospective state-feature model fails size/burst transfer and is not
   integrated into DSE.
5. **Task/cost:** verify pi0.5 shapes against the deployed checkpoint; use measured
   success data and calibrated area/energy before final task-aware hardware ranking.

The prior-only runs contain no native measurements. The Phase 2 calibration uses
real Ramulator execution, not physical silicon measurements or NeuSim compute
calibration. Workload dimensions, utilization, area and energy remain provisional.
Deterministic scheduling can still produce periodic L/S variation; zero input noise
does not guarantee zero standard deviation.

For the executable native calibration path and Einstein batch workflow, see
`docs/NATIVE_WORKFLOW.md`. Prior-only runs above remain analytical; native campaign
outputs explicitly record whether the backend executed and which setup was used.
